CINE DE NICHO · SEGÚN CÓMO TE SIENTES

No busques un título. Elige una sensación y desliza hasta encontrar la película que hoy te va a hablar — incluidas las joyas que nadie más te está recomendando.

Esta app necesita una API key gratis de TMDB para traer películas (te la dan al instante, sin tarjeta).
1. Crea cuenta en themoviedb.org/signup
2. Ve a Configuración → API → pide una "API Key (v3 auth)"
3. Pégala aquí abajo:
Elige una sensación
Selecciona un mood arriba y presiona "Buscar" para empezar a deslizar.
